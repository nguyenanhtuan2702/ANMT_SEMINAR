# Dữ liệu
Đặt file `logs_SPEDIA_annotated_en.csv` đã tải vào `data/raw/` để dùng cục bộ.
Dataset không được đóng gói trong bộ khung. Upload CSV trên giao diện có thể chọn từ bất kỳ thư mục nào.
`raw/` giữ bản gốc, `processed/` dành cho dữ liệu sinh ra sau chuẩn hóa.
Hai thư mục này được bỏ qua bởi Git, ngoại trừ `.gitkeep`.
Không sửa đè dataset gốc. File SPEDIA.pdf là tài liệu tham khảo, không phải dữ liệu đầu vào.
