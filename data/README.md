# Dữ liệu
Đặt file `logs_SPEDIA_annotated_en.csv` đã tải vào `data/raw/` để dùng cục bộ.
Upload CSV trên giao diện có thể chọn từ bất kỳ thư mục nào.
`raw/` giữ bản gốc cục bộ và được bỏ qua bởi Git. `processed/` chứa bundle
chuẩn hóa cùng schema, manifest, kết quả rule/correlation và tài liệu dữ liệu.
Không sửa đè dataset gốc. File SPEDIA.pdf là tài liệu tham khảo, không phải dữ liệu đầu vào.
